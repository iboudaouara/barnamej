// about

Built on fundamentals, not frameworks of the month.

Go Python Rust C POSIX Linux

Barnamej takes on the engineering work that doesn't tolerate shortcuts: services that need to stay up, tools that need to run unattended, and pipelines that need to produce the same correct answer every single time.

The approach favors low-level, performance-oriented languages and a terminal-first workflow, because systems built that way tend to stay predictable long after the first release. Every engagement starts with understanding the actual constraint, not the trendiest way to work around it.

No bloated dependency trees. No solutions in search of a problem. Just software that does what it says on the tin.

// services

What gets built

Three areas of focus, each grounded in tools chosen for the job rather than convention.

Backend API Development

Services and APIs built in Go or Python, designed around clear data contracts, sane error handling, and infrastructure that doesn't page you at 3am.

  • REST & RPC service design
  • Database schema & query design
  • Authentication & access control

Custom CLI Tools & Automation

Command-line tools and system automation written in Rust or C, built to run unattended, fail loudly when something's wrong, and stay fast under load.

  • Internal developer tooling
  • Scheduled jobs & system daemons
  • Workflow & process automation

Scientific Data Processing

Pipelines for large or awkward datasets, from binary format conversion to HPC-scale processing, built for correctness first and speed second.

  • Data format conversion & virtualization
  • Batch & HPC processing pipelines
  • Large-scale dataset optimization
